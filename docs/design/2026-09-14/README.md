## 적용 순서

1단계(색·폰트·모서리 토큰)는 커밋 `7bf546c` 에서 끝났다. `VicaColors` 열 몇
줄과 테마만 고쳐 225곳이 함께 바뀌었고 화면 배치는 건드리지 않았다.

2단계는 화면별 배치다. 화면 하나씩, 위 이미지에서 그 화면만 잘라 붙이고
고친다. 한 번에 여러 화면을 건드리면 스타일이 흩어진다.

## 주의

시안에는 **기능을 더하거나 빼지 않았다.** 배치만 바꿨다. 옮기다가 버튼이나
입력칸이 사라지면 시안이 아니라 옮기는 쪽이 틀린 것이다.

`01-design-system.png` 안의 설명 문구 일부(글꼴·radius 수치)는 시안을 만든
중간 단계의 것이라 최종과 다르다. **색은 이미지가 맞고, 글꼴과 수치는
`vica_ui.dart` 가 맞다.**
